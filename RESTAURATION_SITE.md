# 🚨 RESTAURATION DU SITE TOMCLAIR.TECH

## Problème identifié
Le site https://tomtechclair.github.io/tomclair.tech/ affiche une application météo au lieu du site Jarvis.

## Solution - Étapes à suivre

### 1. Ouvrir GitHub Desktop
- Lancez GitHub Desktop
- Connectez-vous à votre compte GitHub

### 2. Cloner le repository
- Allez dans "File" > "Clone Repository"
- Sélectionnez "tomtechclair/tomclair.tech"
- Choisissez un dossier de destination

### 3. Remplacer les fichiers
Dans le dossier cloné, remplacez ces fichiers avec ceux de `C:\Users\tomg-\OneDrive\Bureau\SITE\` :

- `index.html` (Site Jarvis complet)
- `script.js` (JavaScript avec FAQ et smooth scroll)
- `style.css` (Styles CSS)
- `JARVIS_Setup_v4.zip` (Fichier d'installation)

### 4. Commit et Push
Dans GitHub Desktop :
- Les fichiers modifiés apparaîtront dans "Changes"
- Ajoutez une description : "Restauration du site Jarvis - correction du contenu"
- Cliquez sur "Commit to main"
- Cliquez sur "Push origin"

### 5. Vérification
- Attendez 2-3 minutes pour la mise à jour de GitHub Pages
- Visitez https://tomtechclair.github.io/tomclair.tech/
- Le site Jarvis devrait être restauré
